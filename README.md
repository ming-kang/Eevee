# Eevee

Eevee 是基于 [Pi Durable](https://github.com/earendil-works/pi) 构建的主动型智能体（Proactive Agent）：Router 对接并拆分工作，以工单的形式交给 Worker.

> 目前处于开发初期（`0.0.1`）
>

## 安装

需要 Node.js 26 或更高版本。尚未发布到 npm，从源码构建：

```bash
npm install
npm run build
node dist/cli/index.js start
```
