# 06 WebUI 思路

参考 `ming-kang/Sash` 的本地服务模式，系统不打包 Electron，由后台 `Engine` 在 `http://127.0.0.1:<port>/ui/` 直接提供 WebUI。使用说明见 [使用面板](../web.md)。

## 核心思路

- **默认安静但不隐藏过程**：面板只主动突出需要人处理的事。正常运转的工单不产生通知或待办，但其对话、工具和作业始终可以查看。
- **“需要你”只有一种**：有待回答的问题，即工单阶段满足 `STAGE_NEEDS[stage] === "user"`（`answer`），或 Router 自己在等你回答。等 Router 处理的 `review`、`blocked` 由 Router 和 Engine 推进，不算需要你。
- **一种强调色**：琥珀只表示“需要你”。红色只表示受阻和失败，其余状态都是灰色，每个 `TicketStage` 一个图形，靠形状区分。焦点环和选区用另一种颜色，不承载状态。
- **单一状态位**：工单行、项目行右侧只放一种状态，按优先级取最要紧的一种；项目行是待回答数量 > Router 失败 > 有工单在执行 > 最近活动时间。
- **先折叠，再展开**：工具调用、调度动作、报告、文件改动、命令和作业通知默认是一行灰字，正文只留 Router 和 Worker 说的话。
- **动效只在焦点处**：列表、侧栏、工单引用都不动；只有正在运行的那一行（一道流光扫过）、正在输出的回复会动。尊重 `prefers-reduced-motion`。
- **让布局解释自己**：不写副标题、说明文字和提示语，等价命令、字段说明只在确实需要时放进 `title`。一个界面要靠说明才看得懂，就改布局。
- **Worker 是一等观察与介入界面**：可以点进任意 Worker 查看完整、实时的执行对话和工具结果，直接发送引导、排队消息或打断，查看报告与后台作业，终止作业。直接介入不是审批流程，也不要求用户逐条确认工具调用。
- **角色能力按角色配置**：设置界面分别为 Router、Worker、Dreamer 启用或停用扩展（包括 MCP 服务器），并查看各角色当前能力。不为每张 Ticket 增加一套设置负担。

## 布局

| 区域 | 内容 |
|:-:|:-:|
| 左栏 | 品牌行与收起按钮、“新建项目”“搜索”（命令面板）、项目列表、底部记忆 / 花费 / 设置三个图标；可收成图标栏 |
| 主区域 | 始终是对话：Router 主对话，或某张工单的 Worker 对话 |
| 右栏 | 标签切换：工单 / 作业 / 详情，详情只在 Worker 对话里出现 |

窗口宽度不超过 1240 时右栏变成抽屉，不超过 760 时左栏也变成抽屉。断点按视口容器宽度（容器查询）判断。

- **右栏·工单**：“需要你 / 进行中 / 已结单”三组，组内按 `TicketStage` 顺序；只有等你回答的工单多一行问题摘要。切到别的标签时，有待回答问题则“工单”标签旁亮琥珀点。
- **右栏·作业**：全项目正在运行的后台作业，可看日志尾部、跳到所属工单、终止。
- **右栏·详情**：当前工单的目标、输入、验收标准、产物、交付给、模型和报告。
- **主对话**：`ticket` / `ask_user` 调用合成一行调度行；引擎投递的报告是一行灰字（`progress` 不显示）；`reset` 只留一条分隔线；失败的一轮显示原因和“重试”。有待回答的问题时，提问卡片占住输入框的位置，推荐选项预先选中，可以“稍后”收成一行提示条。
- **管理页面**：记忆（项目 / 全局、按作者区分的历史、diff、撤销、未提交的手动改动、文件浏览）、花费（总览、按模型、按对话）、设置（模型、角色能力、MCP 与扩展、Engine）。

刻意不做的：跨项目的“需要你”汇总页（由项目行的琥珀角标代替）、工单栏里的“当前动作”和进度条、按天的花费、头部的模型和路径芯片。

## 视觉与动效

层次靠明度和阴影，不靠描边。每个组件属于一个层级，背景和阴影一起由层级决定：

| 层级 | 用途 |
|:-:|:-:|
| well（凹槽） | 盛放值的东西：输入框、关着的开关、分段控件的底槽 |
| page（页面） | 应用底色与对话 |
| region（区域） | 左栏、右栏，卡片里的一块 |
| card（卡片） | 输入框、提问卡片、设置分组 |
| floating（浮层） | 菜单、命令面板、悬停卡片、提示 |
| modal（对话框） | 对话框，下面盖一层遮罩 |

- **尺寸只取几档**：圆角 5 / 8 / 10 / 14（支持时用 `corner-shape: squircle`），控件高 28 / 32 / 36，字号 11 / 12 / 13 / 14 / 16 / 18，图标 14 / 16 / 18 / 22。列表的行、标题、输入框和菜单项用 14，按钮和工具行用 13，次要信息用 12；11 只给数字、按键和等宽编号，中文至少 12。控件文字字重 500、字距 -0.01em。
- **字号可调**：字号和图标都按同一个界面字号成比例换算，默认 14，设置里可选 13 到 16；控件高度不变，放大后只是字更大，布局不会松散。首帧前就按保存的字号绘制。
- **字体随面板打包**：Inter Variable 与 JetBrains Mono Variable 由 `@fontsource-variable` 打进面板，离线可用；中文先点名苹方、微软雅黑、思源黑体，再回落到系统字体。
- **底色是中性灰**：浅色页面是近白的灰，左右栏再深一档，卡片和输入框是纯白，浮在最上面。深色是带一丝冷调的石墨灰，页面最深，栏和卡片逐档变亮。
- **深色文字有亮度上限**：纯白字在近黑底上久读会发晕。界面文字对页面约 13:1，正文高一档，粗体再高一档，都不到纯白；左栏的行比界面文字再低一档，只有当前所在的那一行回到界面文字的亮度。
- **动效三档**：120ms（悬停、按下）、180ms（开关、标签、展开）、320ms（抽屉、侧栏宽度），同一条缓动曲线。按下时控件下沉 1px、阴影收起；浮层出现时上浮 4px；分段控件（右栏标签、记忆页切换、主题、引导 / 排队）只有一块滑动的底板；弹出列表的高亮立即跟手，不做过渡；提示从顶部落下。
- **强调色只做三件事**：焦点环、选中、存下来的“开”（开关、单选）。浅色是蓝色，深色是浅青色；它从不单独出现成一个点或一个数字，不会和“需要你”的琥珀混淆。开关和单选打开时是强调色底加高光，开关的滑块始终是凸起层。
- **焦点环只给键盘**：按 Tab 或方向键移动时才画焦点环；用鼠标或触屏时不画，点开抽屉、关掉对话框后交回的焦点也不会亮起。文本框例外，输入时始终标出位置。

## 实现方案

- **单向数据流**：WebUI 只负责显示和发起 RPC，所有写入都由 `Engine` 完成，写完不手动刷新，等流推送。
- **实时流取代轮询**：每个页面一条到 `/api/stream` 的 WebSocket（协议见 `src/api/stream.ts` 与 [实时流](../stream.md)）。每个项目一个看板 watch，供项目行和右栏使用；当前 Router 对话和打开的 Worker 对话各一个对话 watch，用 Durable 的 `ConversationTranscript` 应用值与 ops，重连时以 `resume` 为窗口续订，用 `entries` 补缺口和向前翻页。项目列表在每次 `hello` 和新建项目后取一次 `GET /api/status`。断线后指数退避重连，期间左栏显示断线提示。
- **识别 Engine 重启**：`hello` 带上 Engine 每次启动生成的 `bootId`。前端发现它变了，就丢掉全部状态重新订阅，避免拿旧进程的增量去拼新进程的状态。
- **后端为面板补充的接口**：`GET /api/models` 返回结构化的模型视图；后台作业的日志尾部与终止；记忆文件的列表与读取；`ProjectSummary.activeAt`；看板带 Router 的运行状态与失败原因（`BoardView.router`），非当前项目的状态位靠它。见 [HTTP 接口](../http-api.md)。
- **路由**：hash 路由，不依赖 `vue-router`：`#/p/:pid`、`#/p/:pid/t/:tid`、`#/p/:pid/memory`、`#/p/:pid/usage`、`#/settings/:section`。授权码 `#code=` 先被取走，路由再解析。
- **设计 token 一处定义**：`web/src/styles/tokens.css` 为每个主题给出一组语义值（表面层级、文字层级、强调色、阴影），派生色用 `color-mix` 从它们算出；其余样式只用语义 token，不写颜色字面量，换主题只改映射。明暗默认跟随系统，可在设置里固定；`index.html` 在首帧前写好主题，避免闪烁。
- **纯逻辑与渲染分开**：路由、工单分组、项目状态位、对话条目映射、相对时间、问题草稿、流客户端等都在独立的 `.ts` 里，用 `node --test` 离线测试；组件只负责渲染。
- **键盘与读屏**：命令面板（`Ctrl K`）、收起侧栏（`Ctrl B`）；对话框和抽屉打开时移入焦点、关闭后归还，关着的抽屉不进入 Tab 顺序；标签页和提问选项支持方向键。
- **授权**：页面从 `eevee web` 打开的 URL 里取出一次性授权码换成会话，存在 `sessionStorage` 里；直接打开不带授权码的地址时，只显示连接说明（见 [安全运行](../security.md#本地接口的防护)）。
