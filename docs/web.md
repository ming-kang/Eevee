# 使用面板

面板是 Engine 自带的网页界面：和 Router 对话、回答问题、观察和介入 Worker，以及管理记忆、用量、模型和角色能力。怎样打开面板，见 [日常使用](usage.md#打开面板)。

## 布局

| 区域 | 内容 |
|:-:|:-:|
| 左栏 | “新建项目”“搜索”、项目列表、底部的记忆 / 用量 / 设置三个图标 |
| 主区域 | 当前项目的 Router 主对话，或某张工单的 Worker 对话 |
| 右栏 | “工单 / 作业 / 详情”三个标签，“详情”只在 Worker 对话里出现 |

窗口变窄时，右栏先变成抽屉，用头部的“工单”按钮打开；再窄时左栏也变成抽屉，用头部的菜单按钮打开。点左栏右上角的按钮或按 `Ctrl B`（macOS 上是 `⌘B`）可以把左栏收成一列图标，这个状态会记在浏览器里；收起后鼠标移到左上角的标志上即可展开。

面板只用一种颜色提醒你：琥珀色表示有问题等你回答。红色表示受阻或失败，其余状态都是灰色，靠图形区分。

## 项目列表

每个项目右侧只显示一种状态，按下面的顺序取最要紧的一种：

1. 待回答问题的数量（琥珀色）；
2. Router 上一轮运行失败（红色）；
3. 有工单在执行（转动的图形）；
4. 最近一次活动距今多久。

鼠标停在项目上片刻，会出现一张卡片：工作目录、待回答的问题数、未结和执行中的工单数、运行中的后台作业数，以及最近活动时间。左栏收起后，项目显示为首字方块，有待回答问题时仍带琥珀角标。

点左栏顶部的“新建项目”，填写标题和工作目录即可。

## Router 主对话

主对话只完整显示你和 Router 说的话，其余过程默认折叠成一行灰字，点开查看明细：

| 一行灰字 | 展开后 |
|:-:|:-:|
| 查阅、运行命令等工具调用 | 每次调用的参数、耗时和输出 |
| “建单 t7、t5 · 提问 q3”这样的调度行 | 每张工单和每个问题的明细 |
| “t3 交回报告（受阻）：……” | 受阻和失败的报告带红色图形；进度报告不显示 |
| 一条分隔线 | Router 交接时写下的摘要 |

回答按 Markdown 显示：标题、列表和任务、引用、表格、代码块和链接。正在输出时，没写完的加粗或代码块先按写完的样子显示，末尾跟着光标。回答里的工单编号（`t3` 或 `ticket://t3`）显示成标签，点开进入那张工单；`report://t2#1` 这类其他地址按原文显示。只有网页和邮件链接可以点，在新标签页打开；HTML 按原文显示。鼠标移到代码块上，右上角出现复制按钮。

还没有对话的项目只显示项目标题和输入框，发出第一条消息后输入框回到页面底部。正在进行的一行灰字上有一道流光扫过，结束后停下；模型还没开始输出时，末尾是一行“思考中”。

新内容到来时，对话跟着滚到最新一条。往上翻看时不再跟随，底部出现一个向下的箭头按钮，对方还在输出时按钮上带着进行中的标记；点它或翻回底部后继续跟随。

对方正在运行时发出的消息先排在对话末尾，标着“待送达”，送达后变成普通消息。

Router 上一轮失败时，对话末尾显示失败原因和“重试”按钮。

输入框里按 `Enter` 发送，`Shift Enter` 换行。在同一个页面里切换项目或工单时，没发出的草稿会保留。

输入框左下角的按钮显示这个项目 Router 的模型和思考档位（模型不支持推理时只显示模型）。点开后“模型”“思考”各占一行，悬停或按 `→` 在旁边展开选项，选完菜单不关，可以接着改另一项；`←` 或 `Esc` 返回。选择写进这个项目的 `project.json`，从 Router 的下一次请求起生效；模型列表里的“默认”回到全局设置。

### 回答问题

有待回答的问题时，提问卡片占住输入框的位置：

- 选项是一行单选，推荐答案已经选中，选中推荐项时下方显示推荐理由；
- 都不合适时点“其他…”，直接写下回答；
- 有多个问题时，用右上角的箭头翻页，每次提交当前这一个；
- 点“稍后”把卡片收成一行提示条，先给 Router 发消息，随时再展开。

## 右栏

### 工单

工单分成三组：

| 分组 | 内容 |
|:-:|:-:|
| 待回答 | 等你回答问题的工单，不显示阶段名，第二行是问题摘要 |
| 进行中 | 其他未结的工单，按 [阶段](tickets.md#工单阶段) 排序 |
| 已结单 | 默认收起 |

每张工单一行：阶段图形、编号、标题和阶段名，已结单的不显示阶段名。点开进入它的 Worker 对话。切到其他标签时，如果有问题等你回答，“工单”标签旁会亮一个琥珀点。

### 作业

列出项目里所有正在运行的 [后台作业](tickets.md#后台作业)。点开一个作业可以：

- 查看日志尾部（最近 200 行，最多 64 KB），作业运行期间约每 2 秒刷新一次，并停在最新一行；往上翻看时不再跟随，翻回底部后继续；
- 跳到它所属的工单；
- 终止作业，需要再点一次确认。Worker 会收到作业已终止的通知，和作业自己结束时一样被唤醒。

### 详情

在 Worker 对话里出现，显示当前工单的目标、输入、验收标准、产物、交付给哪些工单、所用模型和全部报告。

## Worker 对话

点开一张工单，主区域换成它的 Worker 对话。头部是返回按钮、工单编号、标题和阶段。

- 对话开头的“开篇”一行打开右栏的详情。
- 文件改动和命令折叠成一行，展开可以看到 diff 和输出；正在运行的命令自动展开，输出停在最新一行。
- 转入后台的命令下面有一行“后台作业 jN 进行中”（结束后是“已结束”），点它打开右栏的作业标签。作业结束的通知也是一行，展开是输出末尾。
- Worker 正在执行时，输入框旁边出现“引导 / 排队”切换和打断按钮，含义见 [观察和介入 Worker](usage.md#观察和介入-worker)。
- 工单有问题等你回答时，提问卡片出现在 Worker 对话里，答案直接投给这个 Worker。

## 记忆

左栏底部的“记忆”打开当前项目的记忆页，顶部可以在项目记忆和全局记忆之间切换。

- **历史**：每次提交一行，标出作者：Dreaming、Router、你，或 Eevee 自己。点开查看 diff，可以撤销一次提交（新建一个 revert 提交，不改写历史）。
- **未提交的改动**：你在编辑器里直接改过、还没提交的文件单独列在最上面。Eevee 下次提交前，会先把它们单独提交为一次 `user edit`。
- **文件**：浏览记忆库里的文件内容。

记忆的工作方式见 [管理记忆](memory.md)。

## 用量

左栏底部的“用量”打开当前项目的用量页：

- 第一行是费用、输入、输出和缓存命中；
- “按模型”列出每个模型的用量；
- “按对话”列出 Router 和每张工单的用量，点工单可以打开它的 Worker 对话。

## 设置

左栏底部的“设置”对全部项目生效，分五页：

| 页面 | 内容 |
|:-:|:-:|
| 通用 | 界面语言（简体中文或 English，切换后页面重新载入）；界面主题（跟随系统、浅色或深色）；字体，填字体名，多个用逗号隔开，留空用自带的 Inter；字号，12 到 20 的整数，默认 14，文字和图标一起缩放。只保存在这个浏览器里 |
| 模型 | 全局和每个角色的默认模型与思考档位；各 provider 的凭据状态，可以在这里填写或更换 API Key；可用模型目录；`models.md` 里的使用经验 |
| 角色能力 | 每个扩展在 Router、Worker、Dreamer 上的开关，以及各角色的轮次上限 |
| MCP 与扩展 | 每个 MCP 服务器的连接状态和错误、用户扩展的加载结果，“重新加载”按钮 |
| Engine | 实时连接状态、版本、地址，以及停止或重启 Engine 的命令 |

在“模型”页的 provider 一行点“填写 API Key”，输入后按 `Enter` 或“保存”，key 保存到 `auth.json`，立即生效；已配置 API Key 的 provider 用旁边的铅笔按钮更换。各项设置的含义见 [选择模型](models.md)、[配置角色能力](capabilities.md) 和 [接入 MCP 服务器](mcp.md)。

## 快捷键

| 按键 | 作用 |
|:-:|:-:|
| `Ctrl K` / `⌘K` | 打开命令面板：跳到页面、工单或项目，新建项目，切换主题，收起侧栏 |
| `Ctrl B` / `⌘B` | 收起或展开左栏 |
| `Esc` | 关闭命令面板、对话框或抽屉 |
| `Enter` / `Shift Enter` | 在输入框里发送 / 换行 |
| `←` `→` | 在右栏标签、记忆页标签和提问选项之间移动 |
| `↑` `↓` | 在命令面板的结果里移动 |

关闭命令面板、对话框或抽屉后，焦点回到打开它之前的位置。跳到别的页面（包括浏览器后退）时，命令面板、新建项目对话框和抽屉一起关闭。焦点环只在用键盘移动时出现。

## 连接

面板通过 [实时流](stream.md) 接收对话和看板的变化，不轮询。连接断开时，左栏底部显示“正在重新连接…”；重连后补齐断开期间的记录。Engine 重启后，面板会重新订阅全部数据。连接状态也可以在“设置 · Engine”里查看。
